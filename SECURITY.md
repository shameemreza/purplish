# Security policy

Purplish runs on WooCommerce stores, so a security issue in it can reach real shoppers. I read and answer every report.

## Supported versions

| Version | Supported |
|---|---|
| 1.0.x | Yes |
| Older | No |

## Reporting a vulnerability

Please don't report a security issue in a public issue or pull request. Open the [Security tab](https://github.com/shameemreza/purplish/security) of this repo and select "Report a vulnerability". Only you and I can see the report.

A good report has the version, the steps to reproduce it, what an attacker gains, and a proof of concept if you have one.

## What happens next

- Within 3 business days: I confirm I got your report.
- Within 14 days of confirming the issue: I ship a fix or send you a plan with a date for it.

Please give me the chance to release the fix before you publish anything about the issue.
